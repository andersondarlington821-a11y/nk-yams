STEP 2: Update Frontend API URLs
══════════════════════════════════════════════════════════════════

IMPORTANT: Use YOUR actual Render URL from Step 1!

Update these 4 files (change "http://localhost:5000" to your Render URL):

1. public/index.html
2. public/register.html
3. public/login.html
4. public/admin.html

Quick PowerShell command to update all at once:

$url = "https://YOUR-RENDER-URL.onrender.com"
Get-ChildItem public\*.html | ForEach-Object {
    (Get-Content $_.FullName) -replace "http://localhost:5000", $url | Set-Content $_.FullName
}


STEP 3: Deploy Frontend on Vercel
══════════════════════════════════════════════════════════════════

Method A: Using Vercel CLI (Recommended)

1. Install Vercel CLI:
   npm install -g vercel

2. Deploy:
   vercel

3. Follow prompts:
   - Set up and deploy? Y
   - Link to existing project? N
   - Project name? nk-yams
   - Override settings? N


Method B: Using Vercel Dashboard

1. Go to https://vercel.com

2. Login with GitHub

3. Click "Add New..." → "Project"

4. Import your GitHub repo

5. Configure:
   - Framework: Other
   - Root Directory: ./
   - Build Command: (leave empty)
   - Output Directory: public

6. Click "Deploy"

TROUBLESHOOTING
══════════════════════════════════════════════════════════════════

"Backend server offline" on frontend:
→ Check API URL in HTML files matches Render URL
→ Verify Render backend is running (check health endpoint)

Backend won't start on Render:
→ Check Render logs in dashboard
→ Verify DATABASE_URL environment variable
→ Ensure Neon database is active

Forms don't work:
→ Open browser console (F12) - check for errors
→ Verify CORS (backend should allow all origins)
→ Check network tab - are API calls reaching backend?
